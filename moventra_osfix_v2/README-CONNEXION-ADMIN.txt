CORRECTION CONNEXION ADMIN

- L’application Moventra Admin ouvre maintenant login.html.
- Une ancienne session Firebase ne permet plus d’ouvrir directement admin.html.
- Après connexion valide, une session temporaire autorise le tableau de bord.
- Déconnexion efface cette autorisation.

Après publication :
1. Supprimer l’ancienne icône Moventra Admin de l’écran d’accueil.
2. Ouvrir /Moventra-transport/login.html dans Safari.
3. Ajouter à nouveau à l’écran d’accueil.
