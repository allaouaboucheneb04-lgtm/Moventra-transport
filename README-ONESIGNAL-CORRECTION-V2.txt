CORRECTION ONESIGNAL V2

1. Publier tous les fichiers à la racine du dépôt.
2. Dans OneSignal > Settings > Push & In-App > Web Settings :
   - Site URL : https://allaouaboucheneb04-lgtm.github.io
   - Si les chemins personnalisés sont affichés :
     Path to service worker files: /Moventra-transport/push/onesignal/
     Service worker filename: OneSignalSDKWorker.js
     Registration scope: /Moventra-transport/push/onesignal/
3. Ouvrir /Moventra-transport/reset-cache.html puis nettoyer.
4. Supprimer l’ancienne icône de l’écran d’accueil.
5. Ajouter de nouveau login.html à l’écran d’accueil.
6. Ouvrir depuis l’icône puis cliquer Notifications et Autoriser.
